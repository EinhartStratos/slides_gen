1. **页数差异**
   - 生成 PPT 为 23 页，真实案例为更多页（模板含大量新建/架构章节）。

   - `项目方案要点` 真实案例有 5 个需求项详细要点，生成版仅列出部分并有些为空模板说明。
   - `项目整体架构图` 生成了 SVG，但架构说明文字偏少。
   - 建议：对 `项目方案要点`、`主要处理流程` 等章节在 prompt 中明确要求按需求项逐条展开；架构图页强制输出不少于 N 条说明。

4. **多出的占位/说明文本**
   - 部分页仍有 `【填写说明】` 等模板占位符残留。
